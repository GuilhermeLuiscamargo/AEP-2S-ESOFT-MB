# AEP-2S-ESOFT-MB

## 📚 Sobre o projeto

Este repositório reúne o desenvolvimento da **Atividade de Estudo Programada (AEP)** do curso de **Engenharia de Software — 2º semestre, UniCesumar**.

O projeto apresenta um sistema de **verificação da situação vacinal de alunos**, relacionado ao **Programa Saúde na Escola (PSE)**. A aplicação foi desenvolvida em **linguagem C (padrão C99)** e funciona no terminal, permitindo organizar registros de vacinação sem solicitar nomes ou outros dados pessoais dos estudantes.

- Desenvolver o sistema em C99.
- Elaborar fluxogramas e documentação das etapas do projeto.
- Preservar a privacidade dos estudantes por meio de identificadores anônimos.

## 💻 Funcionalidades do sistema

1. **Registrar aluno:** informa faixa etária, etapa escolar, vacinas e situação de cada vacina; gera um identificador como `ALUNO-1`.
2. **Consultar alunos:** oferece consulta individual por ID e consulta geral dos registros.
3. **Atualizar aluno:** permite alterar faixa etária, etapa escolar, situação vacinal, adicionar ou remover vacinas.
4. **Excluir aluno:** localiza o registro pelo ID, apresenta os dados e solicita confirmação antes da exclusão.
5. **Sair:** encerra o programa.

O sistema oferece **15 opções de vacinas**, com situação **Em dia** ou **Pendente**, e valida as opções digitadas pelo usuário.

## 🛠️ Tecnologias

- Linguagem **C99**.
- **Dev-C++** para abrir, compilar e executar o código.
- Execução em terminal no Windows.
- Armazenamento temporário em memória durante a execução.
